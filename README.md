# Object Marker

Minimal RuneLite development plugin.

## v0.1

Marks visible game objects named `Fire` with cyan `FIRE` text.

## Local test

Open the project in IntelliJ IDEA with Java 11 and run the Gradle `run` task.

The development RuneLite client loads `ObjectMarkerPlugin` automatically.

## Scope

Current scope is intentionally minimal: one object name and one cyan text label. No sidebar, cloud services, database, automation, or extra configuration yet.
